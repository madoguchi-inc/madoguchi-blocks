# TSK-4158 比較テーブル デザイン刷新（Figma 再現）

- Notion: TSK-4158「アフィリエイトテーブルのデザイン依頼」（みんなの買取）
- Figma: `https://www.figma.com/design/09cMeGFEa866Zmc8rH3DMg/みんなの買取?node-id=13574-15794`
  - テーブル本体 `13574:18113`（PC）／SP は同じテーブルを横スクロール＋1列目固定 `13574:19371`
  - 記号 `13518:2931`（◎△✕✓）／スクロールヒント `13574:15392`

## 要件定義

- Figma デザインを比較テーブル（`madoguchi/comparison-table` + `madoguchi/comparison-row`）の**既定の見た目**として実装する
  （プラグインは複数メディアで共有・自動更新されるため、既存記事のテーブルも新デザインになる。既存のカスタマイズ属性は維持）。
- 2段ヘッダー（列グループ）に対応する。グループ名・グループ色は編集画面から設定できる。
- 記号セルは ◎／✓／△／✕ の4種を SVG で描画し、記号の下に補足テキストを縦並びで置ける。
- 口コミセルは「数値（上）＋★5（下）」の縦並び。数値・星はブランド色（`--md-brand`、既定 `#c4ab46`）。
- CTA ボタンブロックに「電話アイコン」を設定できるようにする（Figma の「電話する」ボタン再現）。
- REST 配信時のテーマ CSS 隔離（`.claude/rules/rest-isolation.md`）とブロック設計ルール（`.claude/rules/block-design.md`）を維持する。

## 仕様

### Figma 値

| 要素 | 値 |
|---|---|
| 罫線 | `#d4dde1` 1px（ヘッダー内のセル間は白 1px）。外枠角丸なし |
| 名称列⇔他列 | `border-right: 3px double #d4dde1` |
| ヘッダー bg | 名称 `#dedede`／通常 `#ededed`／グループ見出し `#f3e3a0`（既定）／配下 `color-mix(グループ色 45%, #fff)` |
| ヘッダー文字 | Bold 12px 左揃え・縦中央。グループ見出し・配下 11px |
| 本文セル | Regular 12px、padding `12px 8px`、左揃え・上揃え。記号＋テキストは縦並び gap 4px |
| 名称セル | Bold 13px、リンク `#3254cd` 下線、縦中央 |
| 記号 | 15px SVG。◎ `#46C446`／✓ `#46C446`／✕ `#C44646`／△ `#FEBF03` |
| 口コミ | 数値 Bold 16px → ★ 12px（`--md-brand`） |
| CTA セル | padding 8px、ボタン中央。ボタン影 `0 3px 0` |
| キャプション | bg `#c3cfd5`、Bold 16px 中央、padding `13px 12px` |
| ヒント | 矢印 SVG 13px ＋ テキスト 14px `#546366`、gap 8px |

### データモデル

- `comparison-table.columns[]` に `group`（string）と `groupColor`（hex）を追加。隣接する同名 `group` を1グループとして 2 段ヘッダー化。
- 既定値変更: `fontSize` 14→12、`cellAlign` center→left。
- `comparison-row.values[i]`（check 列）の `mark` に `circle` / `triangle` を追加。
- `cta-button.icon`（string、既定 `""`、`phone`）。

### 描画（render.php）

- 親: グループがある場合、ヘッダーセルにインライン `grid-column` を明示し、行方向はクラス
  `--span2`（`grid-row: 1 / span 2`）／`--group`（row 1）／`--sub`（row 2）で配置。行 1〜2 が全列埋まるため子行セル（自動配置）は行 3 以降。
  グループが無い場合は従来どおり 1 段。
- 子: 記号は `$mark_svgs`（Figma path）のインライン SVG。口コミ列は `__score` → `__stars` の順。
- CTA ボタン: `icon` 指定時にラベル前へ `<span class="cta-button__icon">` で SVG を出力。`src/condition-card/icons.js`・
  `blocks/recommend-card/render.php`・`blocks/cta-button/render.php` の `phone` path を同期。

### REST 隔離

- `tools/build-rest-css.js` の `INLINE_GUARDS` に `{ sel: '.comparison-table__gcell--head', props: ['grid-column'] }` を追加。
- `--md-group-bg` はカスタムプロパティなので `!important` 化対象外。
